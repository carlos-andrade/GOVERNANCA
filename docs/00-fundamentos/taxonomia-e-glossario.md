# Taxonomia e glossário

| Termo | Definição operacional |
|---|---|
| Portefólio | Iniciativas avaliadas em conjunto quanto a valor, risco, capacidade e dependências. |
| Programa | Projetos coordenados para benefícios relacionados. |
| Projeto | Esforço temporário com resultado, owner e critérios de aceitação. |
| Produto | Capacidade ou serviço mantido continuamente. |
| Domínio | Área funcional, técnica ou de dados com responsabilidade explícita. |
| Gate | Ponto de decisão dependente de evidência e autorização. |
| ADR | Registo de decisão arquitetural, opções e consequências. |
| RACI | Matriz de quem executa, responde, é consultado e informado. |
| SLI/SLO/SLA | Indicador / objetivo de nível de serviço / compromisso formal, quando aplicável. |
| RTO/RPO | Tempo-alvo de recuperação / perda de dados máxima tolerada medida no tempo. |
| Risco residual | Risco restante após os controlos existentes. |
| Exceção | Desvio temporário e aprovado de regra interna. |
| Fonte de verdade | Sistema/artefacto autoritativo para um estado ou dado específico. |
| Evidência | Artefacto verificável que sustenta um resultado ou decisão. |
| Runbook | Instruções operacionais testáveis. |
| Postmortem | Revisão de incidente centrada em factos, impactos e prevenção. |

IDs: `PRJ`, `RSK`, `DEC`, `ADR`, `REQ`, `DEL`, `CHG`, `REL`, `INC`, `EXC`, `AUD`, `ACT`, `DATA`, seguidos de sequência não reutilizável. Datas ISO `AAAA-MM-DD`; não inserir segredos ou dados pessoais nos nomes.
